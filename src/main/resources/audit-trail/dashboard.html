Chain Integrity Verification

Verify the SHA-256 hash chain for any entity record. A broken chain indicates that one or more audit entries were tampered with or deleted after the fact.

How chain hashing works

Each audit entry stores a prevHash — the SHA-256 hash of the previous entry's content. This creates a linked chain from the first to the latest change. If any entry is modified or deleted, all subsequent hashes become invalid, making tampering immediately detectable.

Enable chain hashing in application.properties: 

audit-trail.chain.enabled=true
